# Frontend do NexoDesk

Interface web do NexoDesk, construída com React, TypeScript, Vite, React Router e Axios.

## Comandos

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run build
npm.cmd run lint
```

Por padrão, o frontend consome `http://localhost:8080/api`. Para utilizar outro endereço, defina a variável `VITE_API_URL` antes de iniciar ou gerar a aplicação.

Para executar o sistema completo com API e SQL Server, consulte o [README da raiz](../README.md).
